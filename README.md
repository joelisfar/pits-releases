# Pits

Pits is a macOS app for browsing your Claude Code conversation logs — see active sessions, costs, cache states, and history at a glance.

This repository hosts the public release binaries and the Sparkle auto-update feed (`appcast.xml`). The app source is developed privately.

## Install

Download the latest `.dmg` from [Releases](../../releases/latest), open it, and drag **Pits** into `/Applications`.

## Updates

Pits checks for updates automatically via Sparkle. New versions are signed with EdDSA and verified by the installed app before any update is applied.

## Requirements

- macOS 14 (Sonoma) or later
- Apple Silicon
